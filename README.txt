1. Download https://cdnjs.cloudflare.com/ajax/libs/jszip/3.10.1/jszip.min.js and save it in this folder as jszip.min.js
2. chrome://extensions (or edge://extensions) -> Developer mode -> Load unpacked -> select this folder
3. Open blinkit.com (logged in), refresh once, open one order, click "Download invoice" once.
4. Click the extension icon, load orders.json, click "Test with first order only", then "Download & Zip All Invoices".
